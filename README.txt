PAKET PWA BENTENG BILANGAN

Unggah kelima file berikut ke folder utama repository rodabilangan:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

Langkah:
1. Unduh ZIP dan ekstrak.
2. Buka https://github.com/sukmanasusan29-gif/rodabilangan
3. Pilih Add file > Upload files.
4. Unggah kelima file dari folder hasil ekstrak ke folder utama repository.
5. Pilih Commit changes.
6. Buka https://sukmanasusan29-gif.github.io/rodabilangan/
7. Jika masih tampil versi lama, tutup tab lalu buka ulang. Bila perlu hapus cache/data situs untuk alamat tersebut.
8. Untuk instalasi HP, buka melalui HTTPS di Chrome lalu menu ⋮ > Tambahkan ke layar utama / Instal aplikasi.

Catatan: progres disimpan pada browser/perangkat yang digunakan. Service worker membutuhkan HTTPS (GitHub Pages sudah menggunakan HTTPS).
